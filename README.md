# Circuit Simulation · แผงต่อวงจรไฟฟ้า

**ภาษาไทย** · [English](README-eng.md)

แบบจำลองวงจรไฟฟ้าบนแผงโนด **20 × 20 จุด** ลากวางอุปกรณ์ ต่อสายไฟ แล้วดูกระแส แรงดัน ความร้อน และพลังงานแบบเรียลไทม์ เปิดในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

สร้างมาเพื่อใช้อธิบายโจทย์ฟิสิกส์ไฟฟ้า (เช่น PAT3) ให้เห็นภาพ ไม่ใช่แค่ท่องสูตร

## เปิดใช้งาน

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (`style.css` และ `app.js` ต้องอยู่โฟลเดอร์เดียวกัน) ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์ ถ้าเปิด GitHub Pages ของรีโปนี้ ก็ใช้งานผ่านลิงก์ได้เลย

## ความสามารถ

- **แผงโนด 20 × 20** ลากอุปกรณ์มาวาง ลากจากจุดถึงจุดเพื่อต่อสาย
- **คำนวณจริงทุกเสี้ยววินาที** ด้วยกฎของเคอร์ชอฟฟ์ จึงเห็นปรากฏการณ์จริง เช่น ตัวเก็บประจุค่อยๆ ชาร์จ กระแสในตัวเหนี่ยวนำค่อยๆ เพิ่ม ไดโอดตัดครึ่งคลื่น AC
- **ทิศกระแส / อิเล็กตรอน** สลับดูได้ว่าประจุไหลไปทางไหน
- **วงจรอุดมคติ / วงจรจริง** อุดมคติคือแหล่งจ่ายไม่มีความต้านทานภายใน มิเตอร์อุดมคติ ไดโอดไม่มีแรงดันตก วงจรจริงมีความต้านทานภายในและพิกัดของอุปกรณ์
- **ความร้อนและพลังงาน** อุปกรณ์ร้อนขึ้นตามกำลังที่สูญเสีย มีสรุปพลังงานที่จ่าย ความร้อน และพลังงานที่สะสม
- **ไหม้และระเบิด** (โหมดวงจรจริง) ถ้าเกินพิกัด อุปกรณ์จะไหม้ ระเบิด หรือหลอมขาด แต่ละชนิดแตกเป็นเศษของตัวเอง (หลอดไฟเป็นเศษแก้ว ตัวเก็บประจุฝาปลิวและกระดาษฟอยล์ ถ่านมีน้ำกรดกระเซ็น) พร้อมลูกไฟ คลื่นกระแทก ไฟฟ้าแลบ และรอยไหม้บนแผง ฟิวส์ช่วยตัดวงจรก่อนได้
- **ออสซิลโลสโคป** ดูกราฟแรงดันและกระแสของอุปกรณ์ที่เลือก
- **นำเข้า/ส่งออกวงจรด้วยโค้ดข้อความ** ให้ AI เขียนโค้ดวงจรจากโจทย์ แล้ววางเพื่อสร้างวงจรทันที
- **บันทึกวงจร** ไว้ในเบราว์เซอร์ และย้อนกลับ (Ctrl+Z) ได้
- **ใช้บนมือถือได้** แผงวงจรอยู่ในหน้าจอแรกเต็มแผ่น แถบเครื่องมืออยู่ด้านบน แถบอุปกรณ์อยู่ข้างแผงและกด ≡ เพื่อย่อได้ ปุ่มควบคุมและข้อมูลอยู่ด้านล่าง บนโทรศัพท์จะลดเอฟเฟกต์ให้เองเพื่อให้ลื่นขึ้น

## อุปกรณ์

| อุปกรณ์ | หมายเหตุ |
|---|---|
| แหล่งจ่าย DC | ขั้วบวกอยู่ที่ขา b |
| แหล่งจ่าย AC | ตั้งแรงดันสูงสุดและความถี่ |
| ตัวต้านทาน | ปรับค่า R และพิกัดกำลัง |
| หลอดไฟ | สว่างตามกำลัง P = I²R |
| สวิตช์ | แตะเพื่อเปิดปิด |
| ฟิวส์ | ขาดเมื่อกระแสเกินพิกัด |
| ตัวเก็บประจุ | ค่าเป็นไมโครฟารัด (µF) |
| ตัวเหนี่ยวนำ | ค่าเป็นเฮนรี (H) |
| หม้อแปลง | ขดปฐมภูมิ (`TP`) กับขดทุติยภูมิ (`TS`) จับคู่กันด้วยเลขคู่ ตั้งอัตราส่วนรอบ n ได้ โหมดอุดมคติเป็นหม้อแปลงอุดมคติ (V₂ = n·V₁) โหมดจริงเป็นขดลวดคู่ที่ตั้ง L และค่าคัปปลิง k ได้ ใช้กับไฟสลับ |
| จุดกราว | จุดอ้างอิง 0 V ศักย์ φ ที่ชี้ดูบนแผงวัดเทียบกับจุดนี้ ไม่วางก็ได้ แผงเลือกให้เอง |
| ไดโอด / LED | นำไฟจากขา a ไปขา b |
| โวลต์มิเตอร์ | ต่อขนาน อ่านค่า V(a) − V(b) |
| แอมมิเตอร์ | ต่ออนุกรม อ่านกระแสจาก a ไป b |

## เครื่องมือบนแผง

กดเลข 1–5 บนคีย์บอร์ดเพื่อสลับ

| คีย์ | เครื่องมือ | ทำอะไร |
|---|---|---|
| 1 | อัจฉริยะ (ค่าเริ่มต้น) | ลากจุดเพื่อต่อสาย ลากอุปกรณ์เพื่อย้าย แตะเพื่อเลือก แตะสวิตช์เพื่อเปิดปิด |
| 2 | เลือก | คลิกที่จุดหรืออุปกรณ์ เพื่อปรับค่า พักการทำงาน หรือลบ |
| 3 | หมุน | คลิกอุปกรณ์เพื่อหมุนตามเข็มนาฬิกา 90° |
| 4 | ลบ | คลิกที่จุดเพื่อลบทุกอย่างที่ต่ออยู่ตรงนั้น |
| 5 | ว่าง | คลิกแล้วไม่มีอะไรเปลี่ยน |

"พักการทำงาน" คืออุปกรณ์หรือสายไฟยังอยู่บนแผง แต่ไม่ได้ต่อในวงจร

## โค้ดวงจร (CIRCUIT v1)

หนึ่งบรรทัดคืออุปกรณ์หนึ่งชิ้นหรือสายไฟหนึ่งเส้น พิกัด `x,y` มีค่า 0–19 (x ไปขวา y ลงล่าง)

```
CIRCUIT v1 ideal=1
TITLE ไฟฉาย
DC  3,9 3,7  E=9
B   8,7 8,9  R=20
W   3,7 3,3 8,3 8,7
W   3,9 3,13 8,13 8,9
```

กดปุ่ม **"โค้ดวงจร"** จะมีหน้าต่างลอยขึ้นมา ในนั้นมีพร็อมต์ภาษาอังกฤษให้กดคัดลอกไปวางในแชต AI พร้อมแนบรูปโจทย์ แล้วนำโค้ดที่ AI ตอบมาวางในช่องโค้ด กด **"นำเข้าวงจร"** ได้วงจรบนแผงทันที

รายละเอียดทั้งหมด (ตารางอุปกรณ์ กฎการต่อสาย ข้อผิดพลาดที่พบบ่อย ตัวอย่าง) อยู่ที่ [`docs/circuit-code-spec.md`](docs/circuit-code-spec.md) แนบไฟล์นี้ให้ AI เพื่อให้เขียนโค้ดวงจรจากโจทย์ได้ถูกต้อง

## เวอร์ชัน

เลขเวอร์ชันอยู่ใน `version.txt` และแสดงท้ายหน้าเว็บ ประวัติการแก้ไขอยู่ใน `log.txt` (คลิกเลขเวอร์ชันบนเว็บเพื่อเปิดดู)

## ข้อจำกัด

ยังไม่มีตัวต้านทานปรับค่า ทรานซิสเตอร์ ออปแอมป์ และแหล่งจ่ายกระแส ความเร็วของจุดที่วิ่งบนสายถูกปรับให้มองเห็นได้ ไม่ใช่ความเร็วจริงของอิเล็กตรอน

## เทคโนโลยี

HTML, CSS และ JavaScript ล้วน แยกเป็น `index.html` (โครงหน้า), `style.css` (สไตล์) และ `app.js` (โปรแกรม) ไม่มีขั้นตอน build ไม่มีไลบรารีภายนอก (ยกเว้นฟอนต์จาก Google Fonts) ตัวแก้สมการวงจรเป็นแบบ Modified Nodal Analysis ใช้ตัวแทนเชิงตัวเลขแบบ backward Euler สำหรับตัวเก็บประจุและตัวเหนี่ยวนำ และ Newton-Raphson สำหรับไดโอดและ LED
